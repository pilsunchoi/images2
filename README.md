# 쓰지 않는 저장소

2026-09-27부터 이 저장소는 쓰이지 않는다.

이 그림들은 원래 **book2 — 파이썬을 활용한 무역데이터 분석** 의 노트북이 `raw.githubusercontent.com` 주소로 불러 쓰던 것이다.
지금은 같은 파일이 그 책 저장소 안 `images/` 폴더에 들어 있고, 노트북은 `../images/...` 상대
경로로 부른다. 따라서 책을 고치거나 다시 빌드할 때 이 저장소를 건드릴 일이 없다.

## 지우지 않고 남겨 둔 이유

예전에 이 저장소의 주소를 인용한 강의자료나 글이 있을 수 있다. 지우면 그 그림이 깨진다.
그런 인용이 없다고 확인되면 저장소 설정에서 삭제하거나 보관(Archive)하면 된다.

## 새 구조

| | |
|---|---|
| 그림이 있는 곳 | 각 책 저장소의 `images/` 폴더 |
| 노트북이 부르는 방식 | `![설명](../images/파일이름.png)` |
| 빌드 결과 | Jupyter Book이 `_build/html/_images/` 로 복사 |
